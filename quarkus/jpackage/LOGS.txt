OOXML Compat Normalize - Quarkus diagnostic logs
=================================================

Portable packages keep logs beside the application, following the same pattern used by NexU.

Windows portable ZIP
--------------------

After extracting the ZIP, the application image contains:

  OOXML-Compat-Normalize-Quarkus.exe
  logs\
    ooxml-compat-normalize-quarkus.log

The jpackage launcher passes an application-relative log path, so the log stays in the extracted portable directory instead of the user profile.

Linux portable
--------------

The launcher writes to:

  ./logs/ooxml-compat-normalize-quarkus.log

relative to the extracted portable directory.

Raw JAR
-------

When running the raw Quarkus JAR directly, the default is also a relative path:

  ./logs/ooxml-compat-normalize-quarkus.log

You can still override it with OOXML_LOG_FILE.

Rotation policy
---------------

- maximum active log size: 10 MB
- maximum backup files: 5
- rotate on application start: enabled

Custom log path
---------------

Windows PowerShell example:

  $env:OOXML_LOG_FILE = "$env:TEMP\ooxml-normalize.log"
  java -jar OOXML-Compat-Normalize-java-quarkus.jar

Linux example:

  OOXML_LOG_FILE=/tmp/ooxml-normalize.log ./ooxml-quarkus

The log records startup, audit requests, normalization requests, selected profile, parser validation result, OOXML family, changed part count and errors. It does not intentionally log document contents.

Local UI and context path
-------------------------

The HTTP server binds intentionally to IPv4 loopback only. The default application context path is:

  /ooxml-compat-normalize

so the UI is available at:

  http://127.0.0.1:8080/ooxml-compat-normalize/

and the REST API begins at:

  http://127.0.0.1:8080/ooxml-compat-normalize/api/

The context path can be changed with OOXML_CONTEXT_PATH. The Windows jpackage launcher and open-ui.cmd use the same setting. If a browser resolves `localhost` to IPv6 (`::1`) first, the localhost URL may fail even though the service is running; use the explicit 127.0.0.1 address above.
